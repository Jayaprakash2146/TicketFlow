# TicketFlow
Real-time full-stack ticket booking platform built for high-demand movies and concerts.  Key Features:  Interactive seat map (AVAILABLE, HELD, BOOKED)  Concurrency control (SELECT FOR UPDATE) prevents double bookings  10-min hold TTL with auto-release  Sold-out waitlists with time-limited claim links on cancellation  Automated QR code ticket email.
